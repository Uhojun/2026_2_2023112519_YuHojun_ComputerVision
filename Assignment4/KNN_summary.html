Interpretation

  • Distance metric: Test accuracy ranks L1 39.2% > cosine 38.1% > L2 35.6% > L∞ 18.3%. L∞ looks only at the single largest pixel difference, discarding the information in the other 3,071 values. L2 squares differences, so a few large pixel differences dominate it, while L1 adds all differences with equal weight. Cosine normalizes vector length, which reduces differences in overall image brightness scale.
  • Size of the differences: L1 beats L2 by 3.0-4.3 percentage points in all five folds, a clear difference. L1 and cosine differ by only 0.88 points in cross-validation, about the size of the standard deviation across folds, so neither can be called better.
  • Effect of k: F1 for L1, cosine and L2 peaks at k=5-7 and falls as k grows to 101. k=1 depends on a single nearest image, while a very large k lets unrelated images into the vote.
  • Precision and F1: As k grows, F1 falls while precision stays high. Predictions concentrate on deer, bird and ship, so the other classes are predicted rarely, which raises their precision and lowers their recall. This is why k was chosen by F1.
  • Differences between classes: Ship (F1 52.6%) and airplane (50.0%) score highest and cat (26.9%) lowest. Trucks, automobiles and airplanes are often mistaken for ships (244, 219 and 219 images), and frogs and horses for deer (293 and 261 images). This suggests that pixel comparison is drawn to backgrounds and color layout more than to object shape.
  • Overall level: 39.2% is about four times random guessing, but still low. Raw pixel distances struggle to handle changes in object position, color and background.

Conditions and limitations

  • Data: 50,000 training images and 10,000 test images, as 3,072-dimensional raw pixels with no normalization. To limit CPU time, cross-validation used 20,000 images, 2,000 per class (full run: python knn_cifar10.py --n-cv 50000).
  • Choosing k: k was chosen on 20,000 images, so it may differ from the best value for 50,000. For L1, test F1 at k=3 (39.1%) was slightly higher than at the chosen k=7 (38.7%), but test results were not used to change k.
  • L∞: Its distances are integers with many ties, so results can depend on how tied neighbors are picked.
  • Vote ties: When votes tie, the class of the nearest neighbor is chosen.
  • Implementation check: Distances, evaluation metrics and the confusion matrix matched scikit-learn on a sample of real images.
